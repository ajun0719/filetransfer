📖 项目简介
阿俊快传 是一款完全在局域网内工作的文件传输工具。手机端启动 HTTP 服务后，电脑、平板、其他手机均可通过浏览器访问，实现即时、双向、多用户文件共享。

无需数据线、无需蓝牙、无需第三方云盘，不消耗移动流量。

无论您是想给同事发送工作文档、给家人分享旅行照片，还是给朋友传大型游戏安装包，阿俊快传都能在几秒内完成。

✨ 核心功能
📲 多端互传
手机 App → 浏览器：手机发送文件给任意浏览器访问者。

浏览器 → 手机 App：电脑或手机浏览器直接上传文件到手机。

浏览器 ↔ 浏览器：不同浏览器用户之间直接互传（无需 App）。

👥 智能用户管理
自动注册：每个访问者自动获得唯一用户名（如 游客_A7B3C9）。

在线列表：实时显示所有在线用户及数量。

固定用户：手机端以“手机”身份出现在列表中，方便识别。

📤 灵活发送
多文件多用户：一次选择多个文件，同时发送给多个目标用户。

先选文件再选人：支持先选文件，再勾选目标用户，操作自然。

批量发送：支持文件夹多选，一次性发送多个文件。

📥 安全接收
确认机制：接收方必须手动点击“接收”或“拒绝”，避免误收。

全部操作：支持“全部接受”和“全部拒收”，一键处理。

推送列表：网页端独立“待下载文件”列表，App 端合并到“待接收文件”列表。

🗂️ 传输历史
记录详情：保存每次传输的文件名、大小、方向（发送/接收）、目标用户和时间。

独立页面：历史记录独立于主界面，保持主界面清爽。

📂 文件管理
自定义保存路径：用户可自由更改保存目录（默认 Download/阿俊快传）。

一键打开目录：点击按钮即可通过系统文件管理器定位到保存路径。

缩略图预览：图片文件显示缩略图，非图片显示默认图标。

🖼️ 网页端增强
原图查看：点击缩略图可全屏查看原图。

批量下载：网页端支持一键下载所有待接收文件。

响应式设计：完美适配电脑、平板、手机屏幕。

✨ 其他亮点
二维码扫码：生成访问地址二维码，扫码即连。

地址复制：一键复制访问地址，方便分享。

实时进度：文件传输显示进度条。

心跳保活：自动维持在线状态，避免用户被误清理。

🚀 快速开始
📱 作为 App 用户
安装阿俊快传。

启动服务：点击主界面“启动服务”按钮。

获取地址：查看显示的 IP 地址（如 http://192.168.1.100:8080）。

分享链接：扫码或手动复制地址发给朋友。

发送文件：点击“发送文件”按钮 → 选择文件 → 选择目标用户 → 点击“发送”。

接收文件：在“待接收文件”列表中点击项目，选择“接收”或“拒绝”。

💻 作为网页端用户
打开浏览器：输入 App 显示的地址（如 http://192.168.1.100:8080）。

自动连接：页面加载后自动获得用户名。

发送文件：选择文件 → 勾选目标用户 → 点击“发送给选中用户”。

接收文件：在“待下载文件”列表中点击“接收”或“拒绝”按钮。

📂 保存路径
默认路径：/storage/emulated/0/Download/阿俊快传/

自定义路径：在 App 主界面点击“更改”按钮，输入自定义文件夹名称（保存在 Download 目录下）。

📊 传输历史
App 端：点击主界面“传输历史”按钮查看。

记录内容：文件名、大小、方向、目标用户、时间戳。

清空历史：历史页面提供“清空”按钮。

🔒 安全性
仅限局域网：文件在本地网络传输，不经过任何云端服务器。

无痕传输：不存储用户数据，传输完成后临时文件自动清理。

确认机制：接收方必须手动确认，避免意外接收。

🧩 常见问题
1. 为什么无法访问？
确保手机和访问设备处于同一局域网（连接同一 Wi-Fi 或手机热点）。

检查防火墙/安全软件是否拦截了 8080 端口。

2. 网页端中文文件名乱码？
确保浏览器编码为 UTF-8（现代浏览器默认支持，无需手动设置）。

3. App 端用户列表为空？
确保已启动服务，且其他用户已通过 /connect 连接。

4. 文件接收后找不到？
点击“打开目录”按钮，直接跳转到保存路径。

或手动前往 Download/阿俊快传/ 目录查看。
